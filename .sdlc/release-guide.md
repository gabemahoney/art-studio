# Release guide

## Permissions

- Without a human: commit in the repo checkout or worktree, naming the ticket, merge accepted work into
  the local `main`, and push `main` to origin (gabemahoney/art-studio).
- Never tag, publish releases, force-push or rewrite published history without the User's approval.

## Release process

Release means the accepted work is merged into local `main`, then pushed to origin `main`.
