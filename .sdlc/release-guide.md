# Release guide

## Permissions

- Without a human: commit in the repo checkout or worktree, naming the ticket, and merge accepted work into
  the local `main`.
- Never push, tag, open or merge PRs, or publish to GitHub (gabemahoney/art-studio) without the User's
  explicit approval for each push.

## Release process

Release means the accepted work is merged into local `main`. Nothing further happens unless the User
approves a push.
