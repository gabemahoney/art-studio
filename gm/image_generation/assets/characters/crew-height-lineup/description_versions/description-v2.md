## Revision rule

Any revision attaches each depicted character's approved `reference.png` as an
IDENTITY input alongside the baseline. If a depicted character has no approved
`reference.png` yet, do not change that character's likeness — leave them as they
appear in the baseline, or stop and tell the user which approval is missing. Never
substitute a candidate or paint a likeness from text alone. When a character's
reference changes, this lineup needs a matching revision.
